# IT-Ticket-System
Eine webbasierte Anwendung zur effizienten Erfassung, automatisierten Priorisierung und Zuweisung von IT-Support-Anfragen.

* Dies ist mein erstes eigenständiges Praxisprojekt im Bereich der Wirtschaftsinformatik. Im Zuge der Entwicklung habe ich nicht nur die Programmierlogik mit Python und Streamlit umgesetzt, sondern auch den kompletten Workflow von der lokalen Versionsverwaltung bis hin zur Bereitstellung über GitHub von Grund auf neu erlernt und angewendet.
